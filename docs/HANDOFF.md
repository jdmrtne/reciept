- **The app was already offline-capable** (vite-plugin-pwa precaches the whole shell; camera/print are local device APIs, no network calls anywhere in the core flow). What Phase 12 actually hardens is the two ways a long-running unattended kiosk can hurt itself over time:
  1. **Silent mid-session update.** `registerType: 'autoUpdate'` self-activates and reloads the tab the instant a new build finishes downloading — if that lands while a guest is in EDIT or mid-PRINT, their session (or an in-flight print) is gone. Switched to `registerType: 'prompt'` (`vite.config.ts`): a new SW now installs and **waits**. `main.tsx` wires `onNeedRefresh` to `src/pwa/updateGate.ts`, which calls the provided `updateSW(true)` (skip-waiting + reload) the moment `sessionStore.screen === 'standby'` — immediately if already idle there, otherwise the next time a session ends. No UI/prompt shown to the guest; the reload happens between customers where it's invisible. 4 new tests cover: applies immediately at standby, waits through camera→edit then applies on return to standby, applies exactly once, and a second `armUpdate` after the first arms independently.
  2. **Storage eviction / bloat.** Added `navigator.storage.persist()` at boot (best-effort, swallowed if unsupported/denied — Chrome grants it automatically for installed PWAs anyway, this just also asks for it as a plain tab). Added workbox `cleanupOutdatedCaches: true` so each deploy's precache doesn't just pile up next to the last one forever.

## Important Decisions
- Adapters receive a finished 1-bit `Bitmap1`, not an image; encoding (ESC/POS) is inside the adapter/encoder layer. Real hardware = a `ByteTransport` wrapped by `EscPosAdapter`, so error mapping and chunking are shared and already tested.
- Mock prints through the real encoder/decoder so it can never disagree with real output.
- Brightness/density are gamma (endpoints fixed) and 255/0 are pinned so the white paper never speckles; contrast is linear about mid-gray.
- Default dither = Atkinson, contrast 0 (Atkinson clips: with +15 everything above ~210 printed blank and below ~40 solid black — measured), feed 4 lines, no cut, marginBottom 8 dots. Defaults are untuned for any real printer.
- `PrinterManager.print` returns the in-flight promise for concurrent calls (double tap safe). No automatic retry — the customer taps RETRY.
- No state/UI libraries; no text tools, ever; settings only in localStorage.
