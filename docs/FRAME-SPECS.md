# Frame artwork specs

_Generated by `npm run frame-specs` from the layout engine + frame bands. Do not edit by hand._

Artwork is built at **3× the layout units** (1152 px wide), RGBA, with the photo windows fully **transparent** (alpha 0) and everything else opaque.
The canvas aspect must match within 1.5% (a test checks any PNG you add). Slot rectangles below are in artwork pixels (x, y, w, h).
